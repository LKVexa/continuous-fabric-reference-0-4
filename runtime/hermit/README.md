# HERMIT hosted runtime

This is the hosted runtime subset bundled with Continuous Fabric Reference 0.4.3.
Start and test it through the repository root. It contains the WebSocket gateway,
worker runtime, virtual shell and browser terminal, with CFP integration changes.

The upstream Electron packaging configuration and obsolete development dependency
ranges have been removed from this subset. Desktop packaging is not supported here.
No npm installation is needed for the root application or this runtime subset.
See ../../README.md and ../../docs/AUDIT_0.4.3.md for setup and validation scope.
Original source digests remain in ../../catalog/hermit-provenance.json.
